## Palette — oscilloscope channels

Scopes label CH1 amber, CH2 cyan, CH3 magenta. Using those as the accent
ramp makes the palette instrument convention rather than decoration, and
amber leads because it carries warmth against photographs (the old cyan
read cold and generic-tech). Light theme became warm lab paper; dark theme
became scope-bezel black.

Contrast computed before any CSS was written (script kept out of the repo;
values recorded on /styleguide):

## Motifs (src/components/instrument/)

- `GridBackdrop` — 8pt minor / 40pt major graph paper, <6% opacity, masked
  to fade downward so it never competes with text.
- `WaveDivider` — three traces: `step` is a real second-order step response
  with overshoot and settling (a PID trace), `sine`, and `square` (clock).
- `Annotation` — tick rule + mono uppercase, used as section eyebrows.
- `.brackets` utility → `<Card framed>` for scope-screen corner marks.
- Radii `rounded-lg` → `rounded-sm`: drafted, not soft.

All decorative: `aria-hidden`, never focusable, never the sole carrier of
meaning. Rules recorded in the `design-system` skill.
