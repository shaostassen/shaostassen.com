## Decisions

- **New category `graphics`.** A software raycaster fits none of `embedded`
  / `robotics` / `ml-cv` / `systems-hpc`. Filing it under `systems-hpc` for
  the performance angle would have mislabelled it, and the category chips
  are a navigation aid — a wrong label costs more than a fifth chip.
- **The demo video is the lead evidence.** For a game, 45 seconds of play
  beats any paragraph. Placed directly under Problem so a skimmer hits it
  immediately.
- **`preload="none"` with the screenshot as poster.** The video is 2.6 MB;
  at `preload="none"` none of it is fetched until the visitor presses play,
  so the page costs only the 51 KB poster. Pinned by a test, because this
  is exactly the attribute someone deletes later without realising it is
  load-bearing.
- **Re-encoded, not copied.** The source is 5.9 MB h264 with no audio
  track; `-crf 30 -preset slow -movflags +faststart` gives 2.6 MB at the
  same 640×480, and faststart lets it start playing before it finishes
  downloading.
- **`featured: false`.** It is a high-school project and the landing strip
  should stay current work. It is fully browsable at /projects.
- **The dead maze generator is the "what I'd do next".** A complete
  recursive-backtracker generator that nothing calls is a more honest and
  more interesting closer than an invented ambition.

## Gotchas

- **Video accessibility needed care that axe cannot check.** The clip has
  **no audio track** (confirmed with `ffprobe` — one video stream, zero
  audio), so WCAG 1.2.2 captions do not apply; what applies is 1.2.1, a
  text alternative for time-based media. The description therefore lives in
  a real `<figcaption>`, tied to the video with `aria-describedby`, and
  describes what happens rather than labelling it "gameplay video". axe
  passes either way — it would not have caught a missing alternative here,
  so this was not something the suite could have told me.
- **Tailwind preflight already constrains `<video>`** (`max-width:100%;
  height:auto`), so the 640-wide element did not overflow the 327px prose
  column at 375px. Checked rather than assumed — measured 327px in 327px.
- `.prose` had styling for `img` but not `video`, `figure`, or
  `figcaption`, so the embed rendered without the border treatment every
  other image gets. Added, matching the `Plate` figcaption so a demo reads
  like the photo plates.
