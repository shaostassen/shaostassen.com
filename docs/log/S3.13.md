## Decisions

- **Lead with the harness, not the cloning.** The cloning models are other
  people's; the contribution is the measurement. The page opens "Why it's
  technically hard" on the case-folding mistake, which is also the repo's own
  headline.
- **`status: in-progress`.** The README says "working end to end, on a small
  scale", and the targeted-splice result is a negative one with a named next
  step.
- **`featured: false`.** Nine projects are already featured; the home strip
  and the `/projects` card count are Shao's call, not mine.
- **Prose, not tables.** The MDX pipeline has no `remark-gfm`, and no
  existing page uses a table, so a Markdown table would render as literal
  pipes. The numbers read fine as sentences.
- **Retraction told, not buried.** The "majority blend" verdict is included
  with its mechanism, per `content-voice` ("honest limitations").
- **Linked the workstation page both ways.** It named SpeechForge as plain
  text with nothing to link to; it now links to `/projects/speechforge`.
