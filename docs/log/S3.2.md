## Done in the 2026-08-02 pass — SpeechLens

Shao asked for SpeechLens to go up. It was blocked on "no measured
results"; that unblocked when its validation runs landed the same day, so
this pass converted it from a listing-only entry to a full case study.

- **Facts come from measured runs, not the draft.** Numbers are from the
  project's own `docs/VALIDATION.md`: a Colab T4 (`large-v3`, float16) and
  an Apple M2 CPU (`small`, int8), same 23.2 s LibriSpeech clip, raw logs
  committed in that repo. The `[CONFIRM]` metric slots in the draft are
  retired: "real-time factor on each target" is now real, and the Orin Nano
  footprint slot was **dropped rather than guessed** — that hardware was
  never measured.
- **Corrected a false hardware claim.** The old `oneLiner` said the project
  runs "on an RTX 5090 and a Jetson Orin Nano". Neither was used: there is
  no NVIDIA desktop GPU in the loop, and the Jetson path is unattempted.
  Replaced with the CPU number, which is both true and the better hook for
  a locally-run tool. See the follow-up below — the same claim still sits
  in `ml-workstation-edge-pipeline`.
- **Kept the project's negative results in the write-up.** The confidence
  gate never fired and the denoise stage lost at every SNR. Both are in the
  Result section. A case study that reports only the wins is less credible,
  and "What I'd do next" is the honest fix rather than humility theater.
- The motivation paragraph is Shao's own from the draft (DSP → how signal
  becomes words → cross-language accent patterns for learners), tightened
  to voice.

## Follow-on the same day — the RTX 5090 correction

Raised the contradiction with Shao; he confirmed the 5090 does not exist.
The 9950X server and the Orin Nano do (I reached the server over Tailscale
to bench on it). Three fixes, all shipped through the full gate:

- **About bio** — claimed "an RTX 5090 workstation feeding a Jetson Orin
  Nano — that carries in-progress projects like SpeechLens". Two errors in
  one clause: the GPU, and the claim that SpeechLens runs on that setup at
  all (it runs on CPU and a cloud T4). Rewritten to the Ryzen 9 9950X
  server and Orin Nano on a Tailscale mesh, "where projects get built and
  benchmarked", which is now literally true.
- **`ml-workstation-edge-pipeline`** — `caseStudy: false` at Shao's
  direction. Its one-liner was also corrected rather than left as-is,
  because listing-only projects still render their one-liner on the
  `/projects` card: unpublishing the route alone would have left the false
  claim visible.
- Verified by grepping the built export: **no occurrence of "5090"
  anywhere in `out/`.**

The listing-only test written earlier in this story re-armed on its own the
moment something became `caseStudy: false` again, and now pins the takedown
(unlinked, 404, absent from sitemap). Skips went 4 → 2, which is how I know
it is actually running rather than silently skipping.
