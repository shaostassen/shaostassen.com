## Decisions

- **README rewritten as a work sample**, not a run-book: stack table with
  the _why_ column, the exact gate commands, current Lighthouse numbers,
  four architecture decisions with their reasoning, and the repo layout.

  live. Footer also dropped "Built with Next.js + Tailwind" — the colophon
  now says it properly — and switched to `profile.ts` for its links.
- Both documents cite decisions that already paid off: the
  `useSearchParams` avoidance (would have emptied the prerendered projects
  list), `light-dark()` theming, build-time Zod validation, and the
  reduced-motion delay bug axe caught.
