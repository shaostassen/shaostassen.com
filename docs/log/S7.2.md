  Zero third-party scripts; revisit any time.

- JSON-LD Person (name, url, sameAs GitHub/LinkedIn, alumniOf Cornell) on
  landing + about. Conservative fields only — no unconfirmed jobTitle.

## Gotchas

- **Metadata image routes are Route Handlers**, so under `output: export`
  they need `export const dynamic = "force-static"` exactly like
  sitemap/robots. Without it: `Failed to collect page data for
  /opengraph-image`.
- **Satori requires explicit `display: flex`** on any element with more
  than one child. The metric line interpolated three nodes
  (`{label}: {value}`) and failed the export; collapsed to a single
  template-literal child.
- Next exports OG images **without a file extension**
  (`/opengraph-image?<hash>`), so a plain static file server reports no
  PNG content-type. The test therefore asserts the PNG magic bytes and a
  sane byte length, plus the `og:image:type` meta — substantive checks
  that don't depend on the server's MIME guessing. Production
  content-type verified separately after deploy.
- Playwright's chromium binary disappeared from the shared cache
  mid-story (unrelated to this work); `playwright install chromium`
  restored it. Symptom: every browser test fails in ~1 ms.
