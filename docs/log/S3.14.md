## Decisions

- **Published now, against my recommendation to wait — at Shao's request.**
  I had advised holding until the first Orin run. Shao asked for it, so the
  page ships with the unmeasured half stated in bold in Result and again in
  the `oneLiner` ("with the Jetson GPU run still to come"), and the metrics
  are CPU-side only. This is the S3.6 / F13 rule applied: no number ships
  that was not measured. Revisit the page when Table 1 exists.
- **`category: systems-hpc`, not `robotics`.** The stated contribution is
  CUDA kernel design and profiling; the controller is the workload. Same
  reasoning as S3.6's `robotics` choice, other way round.
- **No board named as the measured platform.** `PLAN.md` was revised on
  2026-10-15 from an Orin Nano to an **AGX Orin 64 GB**, while the About page
  still says Jetson Orin Nano. Nothing has run on either, so the page says
  only "Jetson Orin" and avoids the question. **Open for Shao:** which board
  he owns, so About and this page agree.
- **GIF → MP4.** `docs/media/cartpole_swingup.gif` is 1.8 MB; the same frames
  as H.264 are 185 KB with a 10 KB poster, `preload="none"`, following the
  demostack figure pattern.
- **Claimed result worded neutrally.** The 99-vs-100 spread is described as
  platform maths libraries (the test's own comment says so), without "my
  reproduction", which would have attributed a sandbox run to Shao.
- **`featured: false`**, as S3.13.
