# S12.1 — Electrons → Instructions

Case study + full-bleed instrument route for the eleven-level digital
abstraction demo. Directed by Shao out of backlog order on 2026-08-02.

## Ideate

The demo lives in its own repo (`visualize_how_electron_produce_real_work`):
eleven levels, 70 tests, zero runtime dependencies, already live on GitHub
Pages. Three ways to bring it here.

1. **Write-up + link out.** The S5.1 precedent exactly — outbound link, no
   iframe, pinned by a test. Zero design conflict, zero gate risk. Rejected:
   this is the piece most likely to get shared, and sending that traffic to
   `github.io` wastes it.
2. **Small embedded teaser.** Mirror `PidLab`: one level restyled to site
   tokens inside the prose, link out for the rest. Fits the design system with
   no exemption. Rejected: the whole thesis is that eleven levels compound and
   the last one closes back onto the first. One level cannot carry that.
3. **Full ladder on its own route.** Chosen. The instrument gets a dedicated
   full-bleed page; the case study stays a normal prose page that links to it.

## The real problem

Not wiring — a direct design conflict.

The design system allows three accent channels, bans raw hex in components,
requires `light-dark()`, and says nothing loops or autoplays. The demo needs six
semantic colors, is dark-only, and animates continuously. Amber-means-not-yet-
settled is how it teaches propagation delay, hazards, metastability and ripple
depth; collapsing six meanings into three would make it prettier and wrong.

Resolved with Shao: a **scoped exemption**, narrowed as far as it goes. Three of
the six meanings already exist in the site palette and are bound to it
(`--e-warn` → CH1 amber, `--e-cya` → CH2 cyan, `--e-vio` → CH3 magenta), so the
exemption is three colors, not six. Documented in the `design-system` skill with
its boundary and its cost.

## Architect

- **Vendored, not installed.** Copied into `src/components/electrons/` by the
  demo repo's `scripts/sync-to-site.sh`. From `node_modules`, Tailwind's scanner
  would not see the class names and the component would ship silently unstyled.
- **Upstream-first discipline.** The sync rsyncs `--delete`, so anything fixed
  in the vendored copy is destroyed on the next sync. Every component change was
  made in the demo repo and synced down. The vendored directory is excluded from
  the site's ESLint and Prettier for the same reason; `pnpm typecheck` still
  covers it, which is the check that would catch a real break.
- **Client boundary.** The page imports
  `@/components/electrons/ElectronsToInstructions` directly, not the package
  barrel. The barrel re-exports the level components, and pulling those into a
  server component makes Next try to run `useState` on the server.
- **`chrome={false}`.** New upstream prop that drops the demo's own `<h1>`,
  `<main>` and footer. A nested `<main>` or a second `<h1>` is a landmark
  violation, not a style problem, so this is a correctness prop.

## What the gates caught

Accessibility was the flagged risk and it was right.

- `text-zinc-500/600/700` measured **1.7–4.1:1** against the panels the demo
  draws on — all below AA. 67 class occurrences lifted to `zinc-400` (6.9–7.8:1).
- axe then failed on the ladder's level numbers: an inline `#565b64` at 2.6:1
  that the first sweep missed because it sits inside a ternary. Swept every DOM
  `color:` property instead of one grep shape — 18 more values across nine files.
- Touch targets: `BitBtn`, `Btn`, `Tabs`, `ToggleChip`, sliders and the datapath
  register buttons were 20–36 px. All now clear 44 px, matching `PidLab`'s `h-11`
  convention. The progress dots keep their 6 px bar inside a 44 px button.

Adding an `embedded` project also broke an existing test that used Embedded as
its known-empty category. Every category now has at least one project, so the
empty state was rewritten around the fact that it is still reachable per-track:
Embedded exists only under Individual work, so School work renders it.

## Result

- `/projects/electrons` — 97 / 100 / 100 / 100
- `/projects/electrons/lab` — 95 / 100 / 100 / 100
- 148 Playwright tests pass (was 142), axe green on both new routes × 2 themes ×
  2 viewports.

## Follow-ups — both closed, same day

Shao asked for the two open gaps to be finished rather than carried.

- **SVG label contrast.** 66 `<text>` fills across 18 files measured 1.9–4.1:1
  and are now on the AA-safe ink. axe never would have caught these — it does not
  audit SVG text — so the gap was invisible to the gate that was supposed to
  protect it. One value is deliberately kept: the dark glyph on a *lit* LED,
  whose background is the phosphor, not the panel.
- **Level-01 autoplay.** The scope now gates on `useVisible()`: off-screen or
  `prefers-reduced-motion` and it holds its last frame instead of running a 50 ms
  timer forever. The component now satisfies the site's "nothing autoplays" rule
  on its own rather than leaning on the exemption for it.

Also fixed on the way: `Mos` decided whether a device was off by comparing its
*colour* (`ch === "#3f3f46"`) rather than its state — which meant a palette
change would have silently broken the label. Rewritten to key off `state`.

Upstream now carries `tests/contrast.test.ts`, which scans the source and fails
on any SVG label or inline DOM colour below 4.5:1, and on any use of the zinc
shades that measured below AA. This was missed twice by hand across two passes;
it should not depend on anyone remembering it a third time.
